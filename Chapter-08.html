8.1 Data URIs (Embedded Learning Assets)

Data URIs allow small images (like learning icons) to be embedded directly into the HTML code as Base64 strings. This reduces HTTP requests, speeding up the load time for educational portals.

8.2 Block Elements (Structuring Reports)

Block-level elements (like <div>, <p>, <section>) always start on a new line and take up the full width available. They form the "bones" of educational reports.

Annual Learning Summary 2025

This entire container is a block-level element. It pushes subsequent content to the next line, creating a distinct section for the report.

8.3 Inline Elements (Data Highlighting)

Inline elements (like `<span>`, `<a>`, `<strong>`) do not start on a new line and only take up as much width as necessary. They are used to style specific data points within a text block.

8.4 Inline-Block Elements (Dashboard Layouts)

display: inline-block allows elements to sit next to each other (like inline elements) but still allows you to set specific width, height, padding, and margins (like block elements). This is ideal for dashboard cards.
