11.1 Syntax & 11.2 Comments (System Documentation)

CSS (Cascading Style Sheets) governs the visual presentation of our educational dashboard. Correct syntax is critical for consistent application across all browsers.

11.1 CSS Syntax

/* Selector targets the element to be styled */
.account-balance {
  color: #004d99; /* Declares the text color */
  font-size: 1.5rem; /* Declares the text size */
}

11.2 Comments in CSS

/* --- BEGIN Q4 2025 STYLING AUDIT --- */
/* Ensure all critical alerts use 'red' */
.alert-critical {
  /* Do not delete: Required by Accessibility Standard AA */
  color: red;
}

11.5 CSS Placement & 11.6 User Agent Styles

Inline CSS

Inline CSS is applied directly to an element using the style attribute.

Internal CSS

Internal CSS is placed within <style> tags in the document's <head>.

External CSS

External CSS is in a separate file (e.g., Education_style.css) and linked via <link>. This is the standard method for global branding.

11.6 User Agent Styles

These are the default styles provided by the browser. Your custom CSS overrides these defaults.
