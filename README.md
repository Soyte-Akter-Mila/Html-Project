# Modern Learning Hub

The **Modern Learning Hub** is a structured, hands-on education portal designed to take students from foundational HTML basics to advanced CSS mastery[cite: 27]. This project serves as a comprehensive curriculum featuring 22 chapters of web development content, interactive status indicators, and a responsive learning interface[cite: 27].

## 📚 Curriculum Overview
The curriculum is divided into two primary learning tracks[cite: 27]:

### 📄 HTML Track (Chapters 01 – 10)
Focuses on the building blocks of web development, including elements, document structure, and semantics[cite: 27].
*   **Chapter 1:** Introduction to container vs. void elements and document tree structure (DOM)[cite: 20].
*   **Chapter 2:** Core elements including advanced tables, interactive image maps, and progress/meter bars[cite: 21].
*   **Chapter 3:** Document emphasis using formatting elements and inline styling[cite: 22].

### 🎨 CSS Track (Chapters 11 – 22)
Covers styling, layout, animation, and adaptive design to create stunning user interfaces[cite: 27].
*   **Chapter 20:** Interactive status through CSS transitions and multi-step keyframe animations[cite: 23].
*   **Chapter 21:** System scalability using CSS variables for global theming, `calc()` for responsive layouts, and automated numbering with CSS counters[cite: 24].
*   **Chapter 22:** Responsive Web Design (RWD) utilizing media queries, fluid grid views, and a mobile-first design strategy[cite: 25].

---

## 🛠️ Technical Features
*   **Global Theming:** Utilizes CSS variables (Custom Properties) in the `:root` for consistent color schemes (Deep Blue/Light Blue) across the hub[cite: 24, 26].
*   **Multilingual Support:** Implements **UTF-8** character encoding to ensure global education symbols and various languages (Bengali, Japanese, Arabic) display correctly[cite: 20].
*   **Interactive Feedback:** Uses smooth transitions and pulsing alerts to indicate system status and lesson completion[cite: 23].
*   **Responsive Layout:** Features a 12-column fluid grid and Flexbox-based module cards that adapt from mobile to desktop views[cite: 25].
*   **Navigation:** Includes a fixed navigation bar with dropdown menus and a persistent bottom navigation bar for quick chapter jumping[cite: 26, 27].
