20.2.3 Animation Delay

The `animation-delay` property specifies a delay for the start of an animation. This is useful for sequencing elements, like showing a success message *after* a module completes.

20.2.4 Animation Iteration Count

The `animation-iteration-count` property defines how many times an animation should play. Setting it to `infinite` creates a continuous loop, essential for status indicators like loading spinners or pulsing alerts in study dashboards.

20.2.6 Animation Timing Function

The `animation-timing-function` property specifies the speed curve of the animation. This is crucial for creating natural-feeling UI interactions in learning modules.
