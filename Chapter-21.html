21.1 CSS Variables (Global Theming)

CSS Variables (Custom Properties) allow us to define theme colors and spacing in one place (`:root`) and reuse them everywhere. This is critical for maintaining consistency across a large learning hub.

Standard Lesson Card

This card uses `var(--primary-theme)` for its border and text color, and `var(--card-padding)` for spacing.

If we change `--primary-theme` in the CSS file, every single card in the hub updates instantly.

21.2 CSS Calculation (`calc()`)

The `calc()` function performs calculations to determine CSS property values. It is essential for mixing units (e.g., pixels and percentages) to create fluid, responsive layouts in study dashboards.

Sidebar
Width: 200px (Fixed)
Main Content Area
Width: calc(100% - 200px)

This area automatically fills the remaining space, ensuring the layout never breaks regardless of screen size.

21.3 CSS Counters (Study Document Numbering)

CSS Counters allow us to adjust the appearance of content based on its location in the document. This is perfect for automatically numbering sections and clauses in long study notes or compliance documents.
