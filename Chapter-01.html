1.1 Two Types of HTML Elements

In education portals, we use two main types of elements to structure content:

1. Container Elements (Normal Elements)

These have a start tag and an end tag. They contain content like course titles or student information.

<h1>Welcome to Modern Learning Hub </h1>
<p>Your learning journey starts here.</p>

2. Void Elements (Empty Elements)

These have only a start tag and no content. Used for visual breaks or metadata.

<hr> (Thematic Break)
<br> (Line Break)
<img src="logo.png"> (Images)

1.2 HTML Document Structure

Every education webpage follows a strict tree structure (DOM). This ensures accessibility tools and screen readers can parse the data correctly.

<!DOCTYPE html>
<html>
<head> <!-- Metadata: Title, Charset, Stylesheets -->
</head>
<body> <!-- Visible Content: Courses, Lessons, Forms -->
</body>
</html>

1.4 Character Encoding (Global Education)

Education is global. We must use UTF-8 to ensure symbols (¥, €, £) and languages (Bengali, Japanese, Arabic) display correctly without data corruption.

<meta charset="UTF-8" />

Examples of Multilingual Support:

  • English: Welcome to My Webpage!
  • Bengali: আমার ওয়েবপেজে স্বাগতম! (Welcome to my webpage!)
  • Japanese: 私のウェブページへようこそ！ (Welcome to my webpage!)
  • Arabic: مرحبًا بكم في صفحتي الإلكترونية! (Welcome to my electronic page!)

1.5 Element Attributes (Configuration)

Attributes provide extra information about elements. In education, they are crucial for linking stylesheets, setting input types, and accessibility.

<input type="password" placeholder="Enter Password" />

1.6 Favorite Icon (Favicon)

The Favicon is the small logo that appears in the browser tab. It is essential for brand recognition in education portals.

<link rel="icon" href="icon/learning Hub.webp" />

(This icon appears in your tab)

1.7 Comments (Internal Documentation)

Comments are not displayed in the browser. Developers use them to leave notes about code logic, reminders, or TODOs for the education team.

<!-- NOTE: Ensure student form includes CSRF token -->
